# 학습 목표

체스판의 현재 상태를 입력 받아 마스터가 선택한 다음 수를 예측한다.

# 데이터의 한 행

game_id, fen, ply, turn, move_uci, result_label

result_label = white_win 1, draw 0, black_win -1

원본은 data/raw, 가공 데이터는 data/processed 그 외의 train,validation등은 data/splits에 저장한다.

# 데이터 출처와 사용 조건

데이터 라이선스: CC BY-SA 4.0
데이터 출처 : https://database.lichess.org/#broadcasts

사용 조건 
1. WhiteFideId와 BlackFideId가 모두 존재 (사람 조건)
2. WhiteElo와 BlackElo가 모두 2300 이상 (실력 조건, FIDE 마스터(레이팅 기준))
3. Variant가 Standard (기보조건, 일반적인 체스 경기)
4. Result in ["1-0", "0-1", "1/2-1/2"]

사용할 데이터

1. 위 사용조건에 만족하는 1000경기
