# Chess AI

## 프로젝트 최종 목표

이 프로젝트의 최종 목표는 모든 마일스톤을 거쳐 사용자가 직접 1:1로 대국할 수 있는 체스 엔진을 완성하는 것입니다.

완성된 엔진은 체스 규칙에 따라 합법적인 수를 생성하고, 현재 보드를 평가한 뒤 탐색 알고리즘과 학습 모델을 이용해 최선의 수를 선택합니다. 프로젝트 초기에는 터미널에서 사람과 AI가 대국하고, 이후에는 별도의 프론트엔드 화면에서 체스판을 조작할 수 있도록 확장할 예정입니다.

```text
사용자 입력
    → 체스 규칙 및 합법 수 검사
    → 보드 평가와 후보 수 탐색
    → 학습 모델을 이용한 수 선택
    → AI의 수 반환
    → 프론트엔드 체스판에 결과 표시
```

### 전체 개발 방향

- M1: 체스 규칙과 사용자 대국 기능 구현
- M2: 보드 평가, Minimax 및 Alpha-Beta 탐색 구현
- M3: AI 자동 대국과 성능 데이터 수집·분석
- M4: 실제 마스터 기보 수집·정제 및 학습 데이터 생성
- M5: 기보를 학습하여 다음 수를 예측하는 모델 완성
- M6: 학습 모델과 탐색 알고리즘을 결합하여 체스 엔진 완성
- 향후 확장: Self-Play 강화학습과 웹 프론트엔드 연결

M6까지 완료하면 학습 모델과 탐색 알고리즘을 사용하는 체스 엔진으로 사용자와 1:1 대국할 수 있습니다. 이후 Self-Play 강화학습을 추가해 엔진의 선택 전략을 개선하고, 백엔드 API와 프론트엔드를 연결해 웹에서도 대국할 수 있도록 발전시킬 예정입니다.

## 프로젝트 소개

Python으로 체스 프로그램과 탐색 AI를 구현하고, 경기 데이터를 수집·분석하며 AI와 데이터 처리 과정을 학습하는 프로젝트입니다.

## Milestone 1 — 체스 게임 기본 기능

### 구현 내용

- `python-chess`로 체스판 생성, 차례 확인, 합법 수 조회 및 기물 이동을 구현했습니다.
- UCI 형식의 사용자 입력을 변환하고, 형식 오류와 불가능한 수를 검증했습니다.
- 합법 수 중 하나를 선택하는 Random AI와 사용자 대 AI 게임 루프를 구현했습니다.
- 체크, 체크메이트, 스테일메이트, 기물 부족, 50수 규칙, 3회 반복을 판정했습니다.
- `pytest`, `monkeypatch`, `capsys`를 사용해 입력과 출력 및 게임 상태를 테스트했습니다.

### 학습한 기술

- 함수의 매개변수와 반환값, 반복문, 조건문, 예외 처리
- `None`을 이용한 종료 신호와 `if __name__ == "__main__"` 실행 구조
- 외부 라이브러리 사용법과 단위 테스트의 기본 원리

## Milestone 2 — Minimax 체스 AI

### 구현 내용

- 체스 기물별 점수를 정의하고 백과 흑의 기물 점수 차이로 보드 평가 함수를 만들었습니다.
- 승리, 패배, 무승부를 반영하는 평가 점수와 재귀 기반 Minimax 탐색을 구현했습니다.
- Alpha-Beta Pruning으로 선택 결과를 유지하면서 불필요한 탐색을 줄였습니다.
- 탐색 깊이를 전달받아 최적의 합법 수를 반환하는 `choose_best_move()`를 구현했습니다.
- 탐색 깊이에 따른 실행 시간을 측정하고 Random AI 대신 Minimax AI와 대국하도록 연결했습니다.
- Minimax와 Alpha-Beta 결과의 일치, 보드 복원, 합법 수 반환을 테스트했습니다.

### 학습한 기술

- 재귀 함수, 탐색 트리, 최대화·최소화 관점의 Minimax 알고리즘
- Alpha와 Beta 경계를 이용한 가지치기 원리
- `board.push()`와 `board.pop()`을 이용한 가상 수 탐색 및 상태 복원
- `float("inf")`, `float("-inf")`와 `time.perf_counter()` 활용

## Milestone 3 — AI 대국 데이터 수집 및 분석

### 구현 내용

- Random AI와 Minimax AI를 동일한 에이전트 구조로 정의하고 자동 대국을 구현했습니다.
- 두 AI의 백·흑 배치를 교환하며 경기 결과, 종료 원인, 전체 기보와 수를 기록했습니다.
- 경기 시간과 AI별 총 탐색 시간, 수의 개수, 한 수당 평균 탐색 시간을 수집했습니다.
- 경기 데이터를 Pandas `DataFrame`으로 변환하고 CSV로 저장한 뒤 다시 불러왔습니다.
- AI별 승·무·패 횟수와 비율, 평균 경기 길이, 평균 및 총 탐색 시간을 집계했습니다.
- Matplotlib으로 경기 결과, 탐색 시간, 경기 길이 분포 그래프를 생성하고 PNG로 저장했습니다.
- 임시 경로와 가짜 에이전트를 활용해 자동 대국, 통계, CSV 저장 기능을 테스트했습니다.

### 학습한 기술

- 함수를 값으로 저장하는 에이전트 설계와 코드 재사용
- Pandas의 `DataFrame`, `loc`, `concat`, `groupby`, `agg`, `rename`, CSV 입출력
- Matplotlib의 막대그래프, 히스토그램, 범례, 축 설정 및 이미지 저장
- 실험 데이터의 구조화, AI별 성능 비교, 테스트 가능한 함수 설계
